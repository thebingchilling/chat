# chat

> **Code agents (e.g. Claude Code): read this file in full before making
> any changes to this repository.**

## Purpose

This repo exists purely as a sandbox so the owner can chat with Claude Code.
There is no application here and nothing in this repo is meant to be shipped.

## Contribution Policy

- Claude Code may freely read, write, edit, and run files in its ephemeral
  cloud container/session workspace while chatting — that's expected and
  fine, and doesn't need to be confirmed with the user each time.
- **Never commit, and never push, any of that work to this GitHub
  repository.** Do not run `git add`, `git commit`, or `git push` in this
  repo for routine chat/work-session changes, and do not open pull
  requests. Treat the working tree as scratch space that is discarded when
  the session ends.
- The one exception is a change to this file (`CLAUDE.md`) itself, when the
  owner explicitly asks for the policy to be updated — that may be
  committed and pushed.
